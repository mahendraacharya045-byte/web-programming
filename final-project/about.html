About Bapsang

Bapsang (밥상) means a table set for a meal. This site is a small cookbook for people who want to cook Korean food at home.

The goal

Make home recipes easy to follow while you cook: clear amounts, steps in order, and tools that save you from juggling a phone, a timer and a notepad.

How it is built

  • Plain HTML, CSS and JavaScript with no frameworks
  • Responsive layout from phone to desktop
  • Semantic landmarks, keyboard support and labeled controls
  • Data saved only in your own browser
