# Week 12 · React Workshop

A refreshed set of React exercises with a matching visual style and updated profile details.

## Pages

- `index.html` — Everyday Edit shopping cart built with React and Vite.
- `add remove item.html` — Task manager with priorities, filters, and progress.
- `lift state between 2 counter.html` — Multiplayer scoreboard with rounds and activity history.
- `toogle visibility.html` — React state details card with a show/hide control.

The standalone exercise pages use local React 18 and Babel files from `vendor/`, so they can be opened directly without fetching those scripts from a CDN. Product photos for the Vite app are stored in `src/assets/products/`.

## Run the Vite app

Install the packages listed in `package-lock.json`, then start the development server:

```sh
npm ci
npm run dev
```

Create a production build with:

```sh
npm run build
```

The generated site is written to `dist/`. Preview it with `npm run preview`.
