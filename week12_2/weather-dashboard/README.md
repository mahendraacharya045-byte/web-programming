# Weather Dashboard

A responsive React app for looking up current weather by city or coordinates, switching light and dark themes, and saving favorite cities.

## Run locally

Run npm install and then npm run dev to start the app.

Build static files with npm run build; Vite writes them to dist/. Weather and geocoding data come from the Open-Meteo API, so an internet connection is required.
