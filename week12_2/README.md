| weather-dashboard/ | Weather dashboard with city and coordinate search |

## Run the React apps

In this folder, run npm install and then npm run dev to start the GitHub Explorer.

For the weather app, run the same commands inside weather-dashboard/.

To build either app for static hosting, run npm run build in its folder. The generated website is written to that app’s dist/ directory.

## Open the standalone exercises

Open any of the four HTML files in a browser. Those pages load React and Babel from a CDN. The profile page also requests example data from JSONPlaceholder, while the two Vite apps use the GitHub and Open-Meteo APIs. These features need an internet connection.
